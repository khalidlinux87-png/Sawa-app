# سوا — اكتشاف المزايا وإنتاج الحملة

## متى تُستعمل
- «ما الذي يميّز سوا؟» / «جهّز حملة» / «اصنع ريلز أو صوراً للإعلان».
- بعد إطلاق ميزةٍ جديدة: أضف لها مقطعاً في `marketing/campaign.json` وأعد التوليد.

## المخرجات (كلّها في `Sawa-app/marketing/`)
| الملفّ | المحتوى |
|---|---|
| `FEATURES.md` | جرد المزايا + تقييم التميّز + الرسائل الرئيسيّة |
| `CAMPAIGN.md` | الخطّة: الجمهور، الأعمدة، جدول ٤ أسابيع، نصوص المنشورات والوسوم |
| `campaign.json` | مصدر المقاطع (الخطّاف، العنوان، العبارات، اللقطة، مستطيل التمييز) |
| `reels/*.mp4` | 1080×1920، ١٥ ث، 30fps، H.264 + مسار صوت صامت |
| `covers/*.jpg` | غلاف الريل (سؤال الخطّاف) |
| `posts/*.jpg` | منشور 1080×1350 للخلاصة (Feed) |
| `src/` | لقطات الهاتف المقصوصة (744×1464) والشعار |

## الخطوات

### ١) اجمع المزايا من المصادر — لا من الذاكرة
1. `Sawa-android/play-store/listing-ar.txt` و`listing-en.txt` (المعلَن رسميّاً).
2. `Sawa-app/HANDOFF.md` و`BUILD.md` (آخر الأقسام: ما أُطلق حديثاً).
3. فحص الكود للتأكّد أنّ الميزة موجودة فعلاً:
   ```bash
   cd Sawa-app; for k in "تنبيهات القرب" "رمز سوا" "قرابة" "محضر" "سرّيّة" "لحظات" "ضعيف"; do
     printf "%s: " "$k"; cat app.p*.js sawa-*.js | grep -o "$k" | wc -l; done
   ```
   ميزة بلا أثرٍ في الكود ⇒ لا تُعلَن.

### ٢) قيّم التميّز (جدول في FEATURES.md)
لكلّ ميزة ثلاث درجات (١–٣): **التفرّد** (هل تقدّمها WhatsApp/Telegram/Zoom/Messenger؟) · **العاطفة** (هل تلمس قيمةً عند الجمهور العربيّ: الأهل، البرّ، صلة الرحم؟) · **قابليّة العرض** (هل تُفهم في ٣ ثوانٍ على الشاشة؟). الأعلى مجموعاً = بطل الحملة. المزايا الشائعة (رسائل، مكالمات) تُذكَر دعماً لا بطولة.

### ٣) اكتب الرسائل
- **خطّاف** سؤالٌ شخصيّ يوقف التمرير (≤ ٦ كلمات)، ثمّ الميزة، ثمّ الدعوة.
- **فصحى فقط** في نصوص سوا (قاعدة C130). الإنجليزيّة نسخة موازية لا ترجمة حرفيّة.
- **لا ادّعاءات غير مثبتة:** لا «الأوّل» ولا «الأفضل». الإتاحة الحاليّة (نوفمبر ٢٠٢٦): **مجّانيّ** · **أندرويد الآن، وApp Store قريباً** — يُضبطان في `common.*.cta/free/avail` في `campaign.json`؛ عند نشر iOS عدّل `avail` وأعد التوليد. الرابط الثابت: `sawaaap.com`.
- النصوص الدينيّة (آية/حديث) كما في `daily.json` مع مصدرها، لا تُختصر ولا تُعدَّل.

### ٤) حدّث `marketing/campaign.json`
لكلّ مقطع: `id`، و`ar`/`en` ‏(hook كلمات، `*` للذهبيّ · title · sub · shot · caps بحدّ عبارتين، `<b>` للتأكيد)، و`hl` مستطيل التمييز بإحداثيّات اللقطة المقصوصة (و`hl_en` إن اختلف التخطيط).
لقطة جديدة: قصّ الهاتف من لقطة المتجر 1080×1920:
```bash
convert sawa-ar-N.jpg -crop 744x1464+168+398 +repage -quality 88 marketing/src/ar-N.jpg
```

### ٥) ولّد
```bash
cd Sawa-app
node .claude/skills/sawa-marketing/scripts/render.mjs --no-video           # الصور فقط (ثوانٍ) — للمراجعة أوّلاً
node .claude/skills/sawa-marketing/scripts/render.mjs --only 03-nearby --lang ar   # مقطع واحد (~٤٠ ث)
node .claude/skills/sawa-marketing/scripts/render.mjs                       # الكلّ (~٨ د لـ١٢ مقطعاً)
```
يحتاج Playwright وffmpeg (موجودان في جلسة السحابة). القالب: `scripts/template.html` — الدالّة `render(t)` تحدّد كلّ إطار، فالتوقيت قابلٌ للتعديل في مكانٍ واحد:
`0–3.4 ث` الخطّاف كلمةً كلمة ← `3.4–5` العنوان والهاتف ← `5–10` تحريك الهاتف إلى العنصر المميَّز + العبارتان ← `10.8–15` بطاقة الختام (الشعار، الشعار النصّيّ، الرقاقات، زرّ التحميل).

### ٦) تحقّق — قبل التسليم، بالنظر لا بالظنّ
```bash
S=<scratchpad>; for t in 1.5 4.5 8 13.8; do ffmpeg -loglevel error -y -ss $t -i marketing/reels/<id>.mp4 -frames:v 1 $S/f$t.jpg; done
convert $S/f*.jpg -resize x700 +append $S/check.jpg     # ثمّ اقرأ الصورة
ffprobe -v error -show_entries format=duration:stream=codec_name,width,height marketing/reels/<id>.mp4
```
افحص: الإطار الذهبيّ فوق العنصر الصحيح (عربيّ وإنجليزيّ) · لا نصّ مقصوص أو متداخل · العربيّة متّصلة الحروف · بطاقة الختام نظيفة · المدّة 15 ث.

### ٧) سلّم لخالد
- قائمة الملفّات **مع حجم كلّ ملفّ** (يعمل من الهاتف).
- ملفّات منفردة لا zip.
- ذكّره: الموسيقى تُضاف داخل Instagram/TikTok (مسار الفيديو صامت عمداً — حقوق الموسيقى).
- ⚠ مجلّد `marketing/` داخل Sawa-app يُنشَر على sawaaap.com عند الدمج في main. إن لم يُرِد ذلك، اقترح نقله أو إضافته إلى الاستثناءات قبل الدمج.

## أخطاء معروفة تجنّبها
- تكبير الهاتف حول عنصرٍ في أسفله يغطّي العنوان ⇒ القالب يُخفي العنوان ويحرّك الهاتف (pan) ليضع العنصر عند y≈1040.
- العبارات السفليّة تغطّي العنصر المميَّز إن بقي في أسفل الشاشة ⇒ نفس الحلّ.
- تخطيط الإنجليزيّة قد يختلف بضع بكسلات ⇒ `hl_en`.
- عنوان إنجليزيّ طويل يلتفّ على سطرين فيغطّي الوصف ⇒ ≤ ٢٢ حرفاً.
